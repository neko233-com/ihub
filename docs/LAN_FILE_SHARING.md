# 内网文件分享

iHub 的内网文件分享是受信任主窗口中的第一方下载工具。它只在用户点击“选择文件并开始分享”并通过系统文件选择器确认后启动，不接受插件、网页或任意路径参数。

## 使用方式

1. 在启动器搜索“内网分享”并打开工作台。
2. 点击选择文件；单次最多 32 个普通文件，总计不超过 64 GiB。
3. 让接收设备接入同一个可信 Wi-Fi 或有线局域网，然后扫描二维码或打开随机链接。
4. 下载完成后点击“立即停止分享”；即使不操作，服务也会在 30 分钟后自动停止。

Windows 防火墙第一次看到局域网监听时可能请求网络访问。只应允许“专用网络”，不要在公共热点或其他不可信网络开放。

## 原生边界

- 宿主 canonicalize 并立即打开系统选择器返回的普通文件。WebView 只收到文件名、大小、统计和一个随机 URL，不收到绝对路径。
- 服务绑定一个随机本机端口，URL 路径包含随机 UUID v4 令牌；只处理这个令牌下的目录页与按编号下载，不解析查询参数、相对路径或用户提交的 URL。
- 只接受 IPv4 私有／回环／链路本地地址以及 IPv6 ULA／回环／链路本地地址，最多同时处理 4 个连接。
- 请求头最多 16 KiB；只支持 `GET` 与 `HEAD`；文件下载固定为 attachment，不支持上传、删除、目录浏览、后台常驻或端口配置。
- 每个已打开文件拥有受锁的顺序读取游标。每次下载都从零开始，同一文件的并发请求不会交叉字节或跳段。
- 共享页使用严格 CSP、`no-store`、`nosniff` 和 `no-referrer`，文件名会在 HTML 与响应头中分别转义。
- 文件内容与 URL 不写入 iHub 历史或插件存储；状态仅驻留当前进程内存。

## 不提供的保证

传输使用局域网 HTTP，不提供 TLS 加密、接收方身份验证或互联网中继。随机路径用于降低偶然发现，不等同于密码；同一网络中的监听者仍可能看到明文流量。因此不要在公共 Wi-Fi、企业不可信 VLAN、VPN 路由、端口转发或敏感文件场景中使用。浏览器开发预览不会打开端口，也不会读取任何本机文件。
