# iHub 设计基线

## Visual thesis

iHub 的启动面不是传统应用首页，而是一整块 uTools / Spotlight 风格的命令面板。Windows 与 macOS 的启动器使用 800 × 504 逻辑像素；在 Windows 150% 缩放下对应约 1200 × 756 物理像素。表面采用 `#303133` 深哑光石墨、`#3a3b3d` 细边和 8px 圆角；没有侧栏、仪表盘或欢迎页。

- 顶部是左对齐的大号输入框 `搜索功能 / 粘贴文件、图片`，右侧仅保留圆形个人/插件中心入口。
- 主区使用九列应用图标网格，分为“最近使用”“已固定”“市场精选”。标题、图标、两行以内的名称与大片留白承担层级；默认不显示卡片说明、标签或营销文案。
- 图标只代表真实可运行的内置工具、已安装插件、系统入口和用户明确固定的本地文件启动项。Windows 本地结果优先显示系统 Shell 的 48px 原生图标，不套彩色渐变底板；异步图标缺失时才保留 Lucide 占位。没有安装的第三方应用不会被伪装成已可用项目。
- 搜索时，三组网格收起为高密度结果列表；结果仍使用同一套哑光背景、简短高亮和键盘选中状态。

## Content plan

1. 启动面：最近使用、固定的内置工具、真实已安装插件和用户右键固定的本地文件/文件夹/应用，以及插件中心/开发者工具/设置入口。
2. 插件中心：由右上角头像或“插件中心”格进入，负责发现、GitHub 导入、安装状态与本地开发链接。
3. 内置工具：本地搜索、颜色、截图、剪贴板历史、JSON、速记、进制转换、计算器、二维码生成与图片识别、受限 WebDAV 云盘目录浏览、屏幕录制、批量重命名和插件模板均在第二层工作面打开；关闭即回到启动器。
4. 设置：自动更新、开机自启动、全局呼出快捷键、最近使用显示和空格执行偏好只出现在第二层，不抢占启动面。

## Interaction thesis

1. 默认 `Alt+Space`（macOS 为 `Option+Space`）在后台时居中唤出，在已经显示且聚焦时再次按下会隐藏；按键自动重复由原生层去抖。可见但暂时失焦时只恢复焦点，不清空查询或插件/工具表面。托盘“显示 iHub”和单实例再次启动始终只显示/聚焦，绝不会反向隐藏。设置页可以录制并原生持久化自定义组合；宿主遇到冲突时保留当前可用键，启动恢复首选失败时才启用已明确展示的备用键，并持续提供“重新尝试 Alt + Space”让用户在占用者退出后即时取回默认键。
2. 失焦、原生关闭请求或空查询下的 `Esc` 都只隐藏窗口，不退出进程；下一次快捷键即时恢复。真正退出由托盘或设置页的“退出 iHub”触发，两处共用同一原生进程退出路径。
3. 输入非空文本立即进入搜索结果；上下方向键选择、`Ctrl/Cmd + ↑/↓` 或 `Ctrl/Cmd + Tab` 切换分组、`Enter` 执行。原生标记为可固定的本地文件、文件夹或应用可右键或用 `Menu` / `Shift+F10` 固定到启动页；前端只传递不透明快捷项 ID，打开前仍由原生层重新解析索引并验证路径。目标失效时固定项会灰化并保留取消固定入口，不会伪装成可启动项目。`Alt+H` 或双击输入框切换最近使用，`Ctrl/Cmd + ,` 打开设置。
4. 插件中心、设置、工具箱和插件前端是启动器之上的单层状态，不会并排堆出多个应用窗口；它们关闭或按 `Esc` 时回到搜索框。
5. 动画只用于 8–12px 的进入、退场和选中反馈，支持 `prefers-reduced-motion`；批量重命名等有副作用的操作必须先给预览，再请求明确确认。
