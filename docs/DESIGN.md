# iHub 设计基线

## Visual thesis

深石墨中的一块精密命令平面：安静、快速、可信，青绿色只用于告诉用户“这里可以行动”。

## Content plan

1. 主工作面：搜索与结果始终优先。
2. 支撑信息：索引状态、范围和刷新行为可见但不抢占注意力。
3. 细节工作面：插件抽屉负责导入、风险和已安装状态。
4. 最后动作：GitHub 导入入口让扩展能力随时可达。

## Interaction thesis

1. 首屏文字以轻量 BlurText 逐字收敛，帮助用户确认当前焦点。
2. 搜索结果用短距离位置过渡，而非大幅弹跳；键盘选择和鼠标悬停共享同一状态。
3. 插件抽屉以紧凑 spring 入场，遮罩只弱化背景，不让工作面消失。

所有动画都可被 <code>prefers-reduced-motion</code> 关闭。组件不依赖繁复卡片堆叠；边界、排版、密度和单一 accent color 承担层级。
