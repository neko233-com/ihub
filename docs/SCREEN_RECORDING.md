# 屏幕录制工作台

iHub 内置录屏使用浏览器／WebView 的 `getDisplayMedia` 与 `MediaRecorder`。用户每次开始录制都必须在受信任的系统选择器中确认实际共享目标；iHub 只提交显示器、窗口或浏览器标签的来源偏好，不能跳过或替用户确认系统授权。

## 当前能力

- 显示器、应用窗口、浏览器标签三种来源偏好；系统选择器拥有最终决定权。
- 轻量 24 FPS / 3 Mbps、标准 30 FPS / 6 Mbps、流畅 60 FPS / 10 Mbps 三档请求参数。WebView 若拒绝码率提示，会安全回退到其默认编码参数。
- 可请求系统音频，但最终可用性取决于 Windows、WebView 和所选目标。
- WebM VP9/VP8 能力协商、暂停、继续、手动停止、共享来源结束自动停止。
- 录制完成立即下载，同时保留当前会话内的本地 Blob 预览与再次下载入口。
- 活跃录制限制为 30 分钟，内存片段限制为 512 MiB；暂停期间不消耗时长额度。关闭工作台会停止并保存，关闭系统选择器后晚到的流不会在后台启动。

## 明确边界

内置录屏不会安装键盘钩子、监听输入、模拟点击或在后台绕过系统选择器。MP4/FFmpeg 转码、全局开始／停止快捷键、按键显示、鼠标点击高亮与视频区域后期裁切需要单独的原生插件、权限声明和 Windows 验收，不能用没有实际实现的 UI 代替。

浏览器 QA 能验证工作台布局、状态和参数生成，但不能证明 Windows 桌面捕获权限或真实媒体帧。桌面验收必须在用户确认系统选择器后执行，并核对开始、暂停、继续、停止、来源结束、WebM 播放与下载。
