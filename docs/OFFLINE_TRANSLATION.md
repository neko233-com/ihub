# 离线翻译语言包

iHub 默认随应用提供中文（简体）⇄ English 基础词典包。翻译、自动语言识别、覆盖率计算和未覆盖片段统计都在当前 WebView 内完成，不访问网络，也不会在没有结果时回退到云端服务。

导入语言包后，工作台会根据已安装包的文字脚本和词条自动检测源语言。相同语言方向的自定义包按导入顺序合并，较新的包优先覆盖内置术语，未覆盖的词条继续使用后续包。没有直接语言对时，如果两侧都存在 English 语言包，工作台会自动使用 `源语言 → English → 目标语言` 的本地枢轴路由，并在结果栏明确显示经过的语言包数量。

其他语言通过“离线翻译 → 语言包 → 导入本地 JSON 语言包”加入。语言包是纯数据，不包含脚本、模型二进制、URL 或安装步骤：

```json
{
  "id": "ja-en-team-v1",
  "name": "Team Japanese English",
  "source": "ja",
  "target": "en",
  "version": 1,
  "entries": {
    "こんにちは": "hello",
    "設定": "settings"
  }
}
```

约束：

- `id` 最多 64 个 ASCII 字母、数字、点、下划线或连字符；`name` 最多 80 个字符。
- `source` / `target` 使用受限 BCP 47 语言代码且不能相同。
- `version` 当前只能是 `1`。
- 每包 1–5,000 个词条，源短语最多 256 字符，目标短语最多 1,024 字符。
- 单个 JSON 文件最大 1 MiB；最多保存 8 个自定义包，总序列化大小最大 2 MiB。两项容量都按 UTF-8 字节计算。
- 控制字符、空词条、畸形 JSON 或超限包会在保存前拒绝。

词典包适合术语、短语和受控文本。枢轴路由不会凭空增加词典覆盖范围：工作台会取两段路由中较低的覆盖率，未覆盖内容保持原样并计数。因此基础词典的结果不会被描述成神经机器翻译。需要更高质量或领域模型时，应准备经过审阅的本地语言包；现有 LibreTranslate 插件仍是独立、需用户明确配置的联网选项。
